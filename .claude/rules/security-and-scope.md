# ルール: スコープと安全性

このアプリは**ローカルで動かす学習用デモ**である。以下を前提・制約とする。

## データ・永続化
- **DB はインメモリ**（`app/db.py` の `store`）。永続化しない。プロセス再起動で seed 状態に戻る。
- 幼稚園データは `app/seed/kindergartens.json` の**架空データ**。実在の園ではない。

## 外部への副作用
- **見学申込は外部送信しない**。`submit_visit_request` は `visit_requests` にローカル記録し
  確認番号を発行するだけ（シミュレーション）。メール送信・外部 API 送信などを追加しないこと。
- エージェントに Bash/ファイル書込などの副作用ツールを与えない（`can_use_tool` で拒否）。

## 認証
- ユーザー ID/PW による**簡易認証**。パスワードは `hashlib.pbkdf2_hmac` でハッシュ化するが、
  トークンはインメモリ管理で失効やリフレッシュを持たない。**本番強度ではない**。
- 認証情報・API キーは `.env` に置き、**コミットしない**（`.gitignore` 済み）。

## エージェント権限
- 許可リスト外のツールは実行しない（`runner._permission_gate`）。
- `max_turns`（`KG_MAX_TURNS`）で暴走を抑止する。

## 変更時の注意
- 上記の「外部送信しない」「インメモリ」「簡易認証」を破る変更を入れる場合は、
  ユーザーに影響（データ送信・保存・課金）を明示して確認すること。
